# EDA-Analysis-Lab
Interactive EDA dashboard built with Streamlit. Upload any CSV to instantly explore distributions, correlations, missing values, and more via dynamic Plotly/Seaborn visuals. Features light/dark mode, auto column detection, and a clean UI – zero code required. 

Upload any CSV file and instantly explore your data with this interactive Streamlit dashboard.
Features: automatic detection of numeric/categorical columns, interactive histograms, boxplots, scatter plots, correlation heatmap, pairplot, missing value analysis, light/dark mode, and a fixed sidebar with a shaded file uploader.
